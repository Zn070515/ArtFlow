# M7b Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Archive a closed activity into a sealed local-volume ZIP package, make `ARCHIVED` an authoritative terminal state, and support an independent unarchive command.

**Architecture:** A new `archive` capability owns the package rows and commands; engine commands gain `close` and `rename`. The runtime builds a whitelist-only ZIP (JSON + CSV), writes it through an `ArchiveStorage` adapter with compensation, and stores the package metadata/hash in PostgreSQL. A single controlled download route verifies size/SHA-256 before streaming.

**Tech Stack:** TypeScript 7, Kysely 0.29, PostgreSQL 18.6, Fastify 5 + TypeBox, Vitest 5, fflate (ZIP), Node fs/promises.

**Spec:** `docs/artflow-plus/specs/2026-10-26-m7b-archive-design.md`

- [ ] **Step 3: Create the archive capability**

Create `plus/packages/domain/src/capabilities/archive.ts`:

```ts
import { capabilityDefinitionHash } from "../compiler.js";
import type {
  CapabilityCompileResult,
  CapabilityCompiler,
  CapabilityDefinition,
} from "../model.js";
import { deepFreeze } from "../model.js";
import type { CapabilityRegistration } from "../registry.js";

export interface CompiledArchiveArtifact {
  readonly version: 1;
  readonly schemaVersion: 1;
  readonly format: "zip-json-csv";
}

export function createEmptyArchiveDefinition(): CapabilityDefinition {
  return { schemaVersion: 1, payload: { version: 1, schemaVersion: 1, format: "zip-json-csv" } };
}

export function compileArchiveDefinition(definition: CapabilityDefinition): CapabilityCompileResult {
  const payload = definition.payload;
  const valid =
    definition.schemaVersion === 1 &&
    typeof payload === "object" &&
    payload !== null &&
    (payload as { version?: unknown }).version === 1 &&
    (payload as { schemaVersion?: unknown }).schemaVersion === 1 &&
    (payload as { format?: unknown }).format === "zip-json-csv";
  if (!valid) {
    return deepFreeze({
      ok: false,
      issues: [{ code: "PAYLOAD_INVALID", message: "Only the zip-json-csv archive format is supported.", path: "payload.format" }],
    });
  }
  return deepFreeze({
    ok: true,
    capabilityKey: "archive",
    contentHash: capabilityDefinitionHash(definition),
    artifact: deepFreeze<CompiledArchiveArtifact>({ version: 1, schemaVersion: 1, format: "zip-json-csv" }),
  });
}

export const archiveCompiler: CapabilityCompiler = {
  capabilityKey: "archive",
  compile: compileArchiveDefinition,
};

export const archiveCapability: CapabilityRegistration = deepFreeze({
  manifest: {
    identity: "archive",
    version: "1",
    dependencies: [],
    conflicts: [],
    definitionSchemaVersion: 1,
    commands: ["archive.activity.archive", "archive.activity.unarchive", "archive.package.read"],
    queries: ["archive.state.read"],
    events: ["ArchivePackaged", "ActivityArchived", "ActivityUnarchived"],
    permissions: ["archive.manage"],
    surfaces: ["studio", "ops"],
  },
  compiler: archiveCompiler,
  emptyDefinition: createEmptyArchiveDefinition,
});
```

- [ ] **Step 4: Add domain lifecycle commands**

In `commands.ts`:

```ts
export function renameActivity(activity: Activity, title: string, expectedRevision: number): Activity {
  if (activity.revision !== expectedRevision) fail("STALE_REVISION", "The activity changed since it was read.");
  if (activity.status === "archived") fail("ACTIVITY_ARCHIVED", "An archived activity cannot be modified.");
  const nextTitle = title.trim();
  if (!nextTitle || nextTitle.length > 200) fail("INVALID_INPUT", "An activity title is required.");
  return deepFreeze({ ...activity, title: nextTitle, revision: activity.revision + 1 });
}

export function unarchiveActivity(activity: Activity, expectedRevision: number): Activity {
  if (activity.revision !== expectedRevision) fail("STALE_REVISION", "The activity changed since it was read.");
  if (activity.status !== "archived") fail("INVALID_TRANSITION", "Only an archived activity can be unarchived.");
  return deepFreeze({ ...activity, status: "closed" as const, revision: activity.revision + 1 });
}
```
