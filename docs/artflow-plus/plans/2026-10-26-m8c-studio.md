# M8c Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Studio activity/definition/session workflow with `studio.manage` enforcement.

**Architecture:** Add a Studio state read endpoint, require `studio.manage` on engine mutations, and build Guided creation + Expert JSON editing in `apps/web`. Execution sessions are started/closed from the active release's declared scopes.

**Spec:** `docs/artflow-plus/specs/2026-10-26-m8c-studio-design.md`

---

### Task 1: Studio permission, state read, route hardening

**Files:**
- Modify: `plus/packages/db/src/definition-repository.ts` (listReleases)
- Create: `plus/packages/runtime/src/studio-service.ts`
- Modify: `plus/packages/runtime/src/index.ts`
- Modify: `plus/apps/api/src/app.ts`
- Test: `plus/apps/api/test/studio.test.ts`
- Modify: `plus/apps/api/test/{http,sse,skeleton}.test.ts`

- [ ] **Step 1: DB `listReleases`**

Add `listReleases(db, activityId): Promise<readonly StoredRelease[]>` ordered by
version desc.

- [ ] **Step 2: `studio-service.ts`**

`getStudioState(db, deps, activityId)`:
- `requirePermission(runtimeActor(deps), "studio.manage")`
- activity summary via `getActivitySummary`
- draft via `getDraft`
- compiled via `getCompiled(activityId, draft.revision)` when draft exists
- releases via `listReleases`
- sessions via `listExecutions`
- return the DTO in the spec; no full compiled artifacts.

- [ ] **Step 3: Harden routes**

Add `requireStudio(request)` in app.ts:
```ts
async function requireStudio(request: FastifyRequest): Promise<RuntimeDeps> {
  const requestDepsValue = await requestDeps(request);
  requirePermission(requestDepsValue.actor ?? SYSTEM_ACTOR, "studio.manage");
  return requestDepsValue;
}
```
Use it for create/activate/compile/release/start/close; replace `deps` with the
returned deps. Keep `requireIdempotency` first so missing-key tests still 400.
Add `GET /api/activities/:id/studio` with the same guard.
Allow `studio.manage` in the `/api/activities` list permission.

- [ ] **Step 4: API tests**

- `studio.test.ts`: studio actor can create/activate/compile/release/start/close
  and read state; participant/ops-without-studio gets 403; state excludes full
  artifacts.
- Update `http.test.ts`/`sse.test.ts`: create a studio account + token in beforeAll
  and use a `studioHeaders()` helper for Studio mutations. Update `skeleton.test.ts`
  to build the app with a studio actor.
- Update the E2E admin seed (`seed-registration.ts`) to include `studio.manage`.

- [ ] **Step 5: Commit** `feat(studio): enforce studio.manage and add state read`.
