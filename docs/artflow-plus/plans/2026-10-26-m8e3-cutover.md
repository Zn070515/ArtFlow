# M8e-3 Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a production-ready Plus image/profile, a Caddy site-profile switch for the main domain, a read-only cutover smoke, and a rollback runbook whose boundary is the first v2 write.

**Architecture:** Plus runs beside v1 on the same host as a Compose profile (`plus-db`, `plus-api`, `plus-web`). Caddy selects a site profile file by environment; switching the main domain is an upstream change from `web:8000` to `plus-web:8080`. Rollback is the reverse change before the first v2 write.

**Tech Stack:** esbuild, Node 24, nginx:alpine, Caddy 2, Docker Compose, Vite.

**Spec:** `docs/artflow-plus/specs/2026-10-26-m8e3-cutover-design.md`

### Task 2: Plus production image and nginx gateway

**Files:**
- Create: `deploy/plus/Dockerfile`
- Create: `deploy/plus/nginx.conf`

- [ ] **Step 1: Write the Dockerfile**

```dockerfile
# syntax=docker/dockerfile:1
FROM node:24-bookworm-slim AS build
RUN corepack enable && corepack prepare pnpm@12.14.0 --activate
WORKDIR /src
COPY plus/package.json plus/pnpm-lock.yaml plus/pnpm-workspace.yaml ./
COPY plus/packages ./packages
COPY plus/apps ./apps
RUN pnpm install --frozen-lockfile
RUN pnpm run build:prod

FROM node:24-bookworm-slim AS api
WORKDIR /app
COPY --from=build /src/apps/api/dist/main.cjs ./main.cjs
ENV NODE_ENV=production \
    APP_ENV=production \
    HOST=0.0.0.0 \
    PORT=3000
EXPOSE 3000
HEALTHCHECK --interval=15s --timeout=5s --retries=5 \
  CMD node -e "fetch('http://127.0.0.1:3000/readyz').then(r=>process.exit(r.ok?0:1)).catch(()=>process.exit(1))"
CMD ["node", "main.cjs"]

FROM nginx:1.27-alpine AS web
COPY deploy/plus/nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=build /src/apps/web/dist /usr/share/nginx/html
EXPOSE 8080
```

Note: the build stage root must include `plus/package.json` as the workspace root;
`pnpm run build:prod` runs from `/src` because the workspace root is copied there.
The file layout above puts the workspace root at `/src` (package.json from `plus/`).

- [ ] **Step 2: Write nginx.conf**

```nginx
server {
  listen 8080;
  server_name _;
  root /usr/share/nginx/html;
  index index.html;
  client_max_body_size 20m;

  location ~ ^/(healthz|readyz)/?$ {
    proxy_pass http://plus-api:3000/$1;
    proxy_set_header Host $host;
  }

  location /api/ {
    proxy_pass http://plus-api:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $http_x_forwarded_proto;
    # SSE (/api/activities/:id/stream) must not be buffered.
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
  }

  location / {
    try_files $uri $uri/ /index.html;
  }

  add_header X-Content-Type-Options nosniff always;
  add_header Referrer-Policy strict-origin-when-cross-origin always;
}
```

- [ ] **Step 1: Write the smoke script**

`scripts/cutover-smoke.mjs` (Node 24, no dependencies):
```javascript
const base = process.env.CUTOVER_BASE_URL;
const publicCode = process.env.CUTOVER_PUBLIC_CODE;
const expectedTitle = process.env.CUTOVER_EXPECTED_TITLE ?? "";
const username = process.env.CUTOVER_STAFF_USER;
const password = process.env.CUTOVER_STAFF_PASSWORD;
if (!base || !publicCode) throw new Error("CUTOVER_BASE_URL and CUTOVER_PUBLIC_CODE are required.");
const failures = [];
async function check(name, run) {
  try { await run(); console.log(`PASS ${name}`); }
  catch (error) { failures.push(name); console.error(`FAIL ${name}: ${error.message}`); }
}
await check("healthz", async () => {
  const response = await fetch(`${base}/healthz`);
  if (!response.ok) throw new Error(`status ${response.status}`);
});
await check("public results", async () => {
  const response = await fetch(`${base}/api/public/results/${encodeURIComponent(publicCode)}`);
  if (!response.ok) throw new Error(`status ${response.status}`);
  const body = await response.json();
  if (expectedTitle && body.activityTitle !== expectedTitle) throw new Error(`title ${body.activityTitle}`);
  if (!Array.isArray(body.results) || body.results.length === 0) throw new Error("empty results");
});
await check("anonymous activities are rejected", async () => {
  const response = await fetch(`${base}/api/activities`);
  if (response.status !== 401) throw new Error(`status ${response.status}`);
});
if (username && password) {
  await check("staff login and activity list", async () => {
    const login = await fetch(`${base}/api/auth/login`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ username, password }),
    });
    if (!login.ok) throw new Error(`login status ${login.status}`);
    const cookie = login.headers.getSetCookie().map((value) => value.split(";")[0]).join("; ");
    const activities = await fetch(`${base}/api/activities`, { headers: { cookie } });
    if (!activities.ok) throw new Error(`activities status ${activities.status}`);
  });
}
if (failures.length > 0) { console.error(`${failures.length} check(s) failed`); process.exit(1); }
console.log("cutover smoke passed");
```
