今年决赛怎么进行

  1. 第一轮：{{ counts.participant_count }} 名选手，分为 {{ counts.group_count }} 组，每组 {{ counts.group_size }} 人。
  2. 按第一轮成绩产生 {{ counts.seat_count }} 个初始席位。
  3. 其余 {{ counts.challenge_count }} 名选手进入第二轮（踢馆），每人 1 次踢馆机会，共 {{ counts.challenge_count }} 次。
  4. 踢馆结束后仍保有 {{ counts.seat_count }} 个席位。
  5. 第三轮：{{ counts.seat_count }} 人按席位顺序演唱。
  6. 第一轮成绩与第三轮成绩按权重合成，产生冠亚季军。

默认值不用改。改完之后系统只会检查这套数字是否自洽。

踢馆人数：{{ counts.challenge_count }} 人（不可填写）

第三轮人数：{{ counts.seat_count }} 人（不可填写）

踢馆人数由「第一轮参赛人数 − 第一轮晋级数」决定；第三轮人数等于第一轮晋级数（踢馆只决定席位，不改变人数）。当前：{{ counts.participant_count }} − {{ counts.seat_count }} = {{ counts.challenge_count }}。

第一轮组数 × 每组人数必须等于第一轮参赛人数；第一轮参赛人数必须大于第一轮晋级数。
